# Команды администратора Decimation Rework

[English](en/ADMIN_COMMANDS.md) · **Русский**

Команды приведены в формате игрового чата. В консоли сервера вводите их без начального `/`. Для административных команд из этого справочника нужны права оператора. Пометка **Игрок** означает, что команда использует позицию, прицел или интерфейс и должна выполняться в игре. Дополнительные условия для меню описаны в [руководстве по админ-хабу](ADMIN_HUB.md).

## Сервер и мир

| Команда | Где | Действие |
| --- | --- | --- |
| `/deciserver help` | Чат или консоль | Краткая встроенная справка. |
| `/deciserver gui` | Игрок | Открывает админ-хаб. |
| `/deciserver reload` | Чат или консоль | Перечитывает `config/decimation/server.properties`. Рассылает обновления тумана, режима DM, экрана смерти и текущего списка источников лута. |
| `/deciserver check` | Чат или консоль | Сообщает, что встроенная проверка обновлений отключена. |
| `/deciserver npc` | Игрок | Открывает администрирование NPC в прицеле в пределах четырёх блоков. |
| `/deciserver power [gui]` | Игрок | Открывает управление городской сетью текущего измерения. |
| `/deciserver zones [gui]`, `/zone gui` | Игрок | Открывает редактор зон и флагов. |
| `/zone list`, `/zone info` | Игрок | Показывает список зон или зоны в текущей позиции. |
| `/zone set <тип>` | Игрок | Создаёт зону выбранного типа из выделения. ID типов доступны через Tab. Варианты команды — `create` и `setzone`. |
| `/zone remove` | Игрок | Открывает редактор. Удаление выполняется в GUI после выбора зоны. `delete` и `erase` тоже открывают редактор. |
| `/zone reload` | Игрок | Перечитывает `zones.json`. В редакторе то же действие выполняет «Загрузить файл». |
| `/deciserver zombies [gui]` | Игрок | Открывает редактор областей, точек и профилей зомби. |
| `/deciserver playerspawn add` | Игрок | Добавляет точку появления в текущей позиции. |
| `/deciserver playerspawn undo` | Игрок | Удаляет последнюю точку из списка. |
| `/deciserver playerspawn gui` | Игрок | Открывает список точек, телепорт и удаление. |
| `/deciserver supplydrop spawn` | Игрок | Запускает поставку по текущим X/Z в основном мире выделенного сервера. |
| `/deciserver supplydrop add`, `undo` | Игрок | Добавляет точку X/Z или удаляет последнюю точку из списка. |
| `/deciserver dmkit create <название>` | Игрок | Создаёт NPC с комплектом из текущего инвентаря администратора. Название до 32 символов. Выдача наборов используется в режиме DM. |
| `/deciserver dmkit remove` | Игрок | Удаляет NPC комплекта в прицеле в пределах шести блоков. |
| `/decivehicles reload`, `/decivehicles sync` | Чат или консоль | Обе команды перечитывают определения транспорта, обновляют загруженные машины и синхронизируют определения с клиентами. |
| `/deciserver weapon damage-debug` | Игрок | Включает или выключает диагностику урона оружия для администратора. |

Старые имена внутри `/deciserver` поддерживаются для скриптов. `supplydropspawn`, `addsupplydropspawn` и `undosupplydropspawn` соответствуют `supplydrop spawn`, `add` и `undo`. `addplayerspawn` и `undoplayerspawn` соответствуют `playerspawn add` и `undo`.

Точки появления хранятся как `X/Y/Z` без привязки к измерению. Точки поставок хранятся как `X/Z` для основного мира. Текущий загрузчик автоматических поставок пропускает первую строку `supplydrop.properties`. Если в списке только одна точка, ручная поставка может работать, а автоматическая не найдёт точек.

## Лут

| Команда | Где | Действие |
| --- | --- | --- |
| `/deciserver loot gui` | Игрок | Открывает редактор и вкладку режиссёра. |
| `/deciserver loot reload` | Чат или консоль | Проверяет и перечитывает конфиги лута. При ошибке валидации остаётся последняя рабочая конфигурация. |
| `/deciserver loot cleanup` | Чат или консоль | Удаляет сохранённое состояние отсутствующих источников в загруженных чанках. |
| `/deciserver loot cleanup --load` | Чат или консоль | Проверяет также выгруженные чанки, загружая их порциями. |
| `/deciserver loot director [status]` | Чат или консоль | Показывает статус и сводку по группам режиссёра. |
| `/deciserver loot director <enable\|disable\|freeze\|unfreeze\|reset>` | Чат или консоль | Включает или выключает режиссёр, замораживает или возобновляет коррекцию, сбрасывает накопленное состояние. |

[Редактор и форматы лута](loot-system-admin.md)

## Дома

| Команда | Где | Действие |
| --- | --- | --- |
| `/deciserver house gui` | Игрок | Открывает список и управление домами. |
| `/deciserver house list` | Чат или консоль | Показывает владельцев, ID и координаты. |
| `/deciserver house freeze`, `unfreeze` | Чат или консоль | Приостанавливает или возобновляет обслуживание домов. |
| `/deciserver house info` | Игрок | Показывает данные дома в прицеле до шести блоков. |
| `/deciserver house extend <дни>` | Игрок | Продлевает выбранный дом на 1–3650 суток. |
| `/deciserver house setowner <ник>` | Игрок | Передаёт дом указанному игроку, который должен быть онлайн. |
| `/deciserver house delete` | Игрок | Удаляет дом в прицеле. |

## Игроки, карта и территории

| Команда | Где | Действие |
| --- | --- | --- |
| `/deci heal [ник]` | Чат или консоль с указанным ником | Лечит указанного игрока онлайн. Без ника лечит отправителя. |
| `/deci caps add [ник] <сумма>` | Чат или консоль с указанным ником | Добавляет положительное целое число крышек. |
| `/deci humanity <add\|remove> [сумма]` | Игрок | Меняет человечность отправителя. Сумма по умолчанию 20. |
| `/deci resetdata` | Игрок | Сбрасывает данные Decimation у отправителя. |
| `/deci item` | Игрок | Выводит внутреннее имя предмета в руке. |
| `/deci region <pos1\|pos2>` | Игрок | Задаёт угол выделения в текущей позиции. |
| `/deci region expand <up\|down>` | Игрок | Меняет верхнюю координату выделения на один блок. |
| `/deci deathhistory <ник>` | Игрок | Открывает серверную историю смертей. |
| `/deci map reload` | Чат или консоль | Перечитывает карту, регионы и серверные метки. |
| `/deci map region list` | Чат или консоль | Показывает зарегистрированные регионы карты. |
| `/deci map marker gui` | Игрок | Открывает карту. Для админских кнопок включите креатив. |
| `/deci map marker list [страница]` | Чат или консоль | Показывает метки с ID. |
| `/deci map marker add <название> <категория> <x> <z>` | Игрок | Добавляет метку в текущем измерении. |
| `/deci map marker remove <id>` | Чат или консоль | Удаляет публичную метку. |
| `/turf create <название>`, `/turf remove`, `/turf reload` | Игрок | Управляет старыми территориями turf. Создание использует выделение, удаление — текущую территорию. Хранилище turf отдельно от зон. |
| `/screenshot <ник>` | Игрок | Запрашивает снимок у клиента игрока онлайн и открывает результат в GUI. |

`/deci` также поддерживает `addcaps`, `fillcaps`, `addhumanity`, `removehumanity`, `pos1`, `pos2`, `expand.up`, `expand.down` и `getitem`. Старые подкоманды `setcondition.bleeding`, `setcondition.infected` и `setcondition.irradiatedd` накладывают состояние на отправителя. `/rspawn` доступна игрокам в зонах с флагом `rspawn` при отсутствии активного боя. `/givemethepowerofdeath` переключает у отправителя состояние `haunted` и в текущем коде доступна обычным игрокам.

## Торговцы

Все команды торговцев выполняются в игре. Креатив дополнительно требуется для редактора ассортимента.

| Команда | Действие |
| --- | --- |
| `/trader help`, `/trader types [1\|2]` | Справка и список базовых типов. |
| `/trader type list` | Список встроенных и пользовательских типов. |
| `/trader type add <id> <базовый_тип>` | Создаёт пользовательский тип на базе существующего встроенного типа. |
| `/trader type remove <id>` | Удаляет пользовательский тип. |
| `/trader create <тип>` | Записывает координаты администратора и создаёт торговца в основном мире. |
| `/trader remove` | Удаляет ближайших торговцев. Алиасы `delete` и `erase`. |
| `/trader reload` | Перечитывает торговые каталоги, заполняет недостающие стандартные данные и пересоздаёт торговцев. |

## Генерация дальней прорисовки

`/dcr generate <радиус>` строит недостающие данные LOD вокруг отправителя. `regen` пересоздаёт данные. Радиус задаётся в чанках. Для удалённого участка или из консоли укажите координаты центра в блоках, например `/dcr generate 0 0 64`. Суффикс `--generate` разрешает создавать недостающие чанки самого мира. `/dcr status` показывает ход задачи, `/dcr cancel` отменяет её.
