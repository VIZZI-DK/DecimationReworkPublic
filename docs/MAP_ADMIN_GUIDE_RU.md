## Быстрый запуск

1. Запустите сервер один раз. Мод создаст каталог `config/decimation/map` и недостающие конфиги.
2. Загрузите изображение карты на публичный HTTPS-сервер.
3. Заполните `config/decimation/map/map.json`.
4. Выполните `/deci map reload` с правами оператора или перезапустите сервер.
5. Возьмите предмет карты и нажмите `M`.

Минимальный рабочий пример:

```json
{
  "schemaVersion": 1,
  "revision": 1,
  "maps": [
    {
      "id": "dayz_main",
      "name": "DayZ Map",
      "dimension": 0,
      "imageUrl": "https://dcmre.work/serverfiles/maps/main-map.png",
      "imageSha256": "",
      "minX": -4000,
      "maxX": 4000,
      "minZ": -4000,
      "maxZ": 4000,
      "defaultZoom": 1.0,
      "minZoom": 0.5,
      "maxZoom": 3.0
    }
  ]
}
```

В JSON необходимо указывать обычный URL. Markdown-запись вида `[https://...](https://...)` работать не будет.

## Доступ игроков к карте

Главная настройка находится в `config/decimation/server.properties`:

```properties
requireMapItem=true
```

- `true` — обычному игроку для открытия большой карты нужен предмет карты в любой ячейке инвентаря.
- `false` — карту можно открыть без предмета.
- администратор в креативном режиме с правами оператора может открыть карту без предмета при любом значении.

Карта открывается клавишей `M`. Клавишу можно изменить в стандартных настройках управления Minecraft.

Предмет карты также показывает изображение текущей серверной карты прямо на своей модели. Правый клик с картой в руке переключает масштаб предметной карты: `1x`, `2x`, `4x`. Выбранный масштаб хранится только в памяти клиента и не записывается в NBT.

## Структура файлов

```text
config/
└── decimation/
    ├── server.properties
    └── map/
        ├── map.json
        ├── markers.json
        ├── icons.json
        └── regions/
            ├── city_center.json
            └── military_base.json
```

- `map.json` — основные карты измерений.
- `regions/*.json` — подробные изображения отдельных участков.
- `markers.json` — постоянные серверные метки.
- `icons.json` — каталог иконок, созданных из ItemStack. Этот файл обслуживает мод; вручную редактировать его не рекомендуется.

При сохранении изменяемых данных используется безопасная запись с резервной копией. Не удаляйте `.backup`, если восстанавливаете повреждённый конфиг.

## Основная карта — map.json

На одно измерение допускается одна основная карта. Всего можно определить до 16 карт.

### Поля карты

| Поле | Назначение |
|---|---|
| `schemaVersion` | Версия формата. Используйте `1`. |
| `revision` | Служебное поле документа. Вручную увеличивать его не требуется. |
| `id` | Уникальный системный ID: строчные латинские буквы, цифры, `_`, `-`, `.`; до 64 символов. |
| `name` | Отображаемое название, до 96 символов. |
| `dimension` | ID измерения: обычный мир `0`, Нижний мир `-1`, Край `1`; у сторонних измерений ID может отличаться. |
| `imageUrl` | Прямая публичная HTTPS-ссылка на изображение. |
| `imageSha256` | Необязательная SHA-256 сумма файла, 64 строчных шестнадцатеричных символа. Можно оставить пустой строкой. |
| `minX`, `maxX` | Левая и правая границы изображения в мировых координатах X. |
| `minZ`, `maxZ` | Верхняя и нижняя границы изображения в мировых координатах Z. |
| `defaultZoom` | Масштаб при открытии карты. |
| `minZoom`, `maxZoom` | Минимально и максимально разрешённый масштаб. |

Изображение сопоставляется с миром так:

- левый край изображения — `minX`;
- правый край — `maxX`;
- верхний край — `minZ`;
- нижний край — `maxZ`.

Соотношение сторон изображения желательно делать таким же, как `(maxX - minX) : (maxZ - minZ)`. Иначе карта будет визуально растянута.

### Ограничения изображения

- только абсолютный публичный URL с протоколом HTTPS;
- локальные, приватные и loopback-адреса запрещены;
- размер загрузки — не более 16 МиБ;
- разрешение — не более `8192 × 8192` пикселей;
- SHA-256 необязателен, но позволяет проверить целостность файла.

Если картинка заменяется по тому же URL без SHA-256, лучше изменить URL, например `main-map-v2.png`. Так клиенты гарантированно не оставят старую версию в кэше.

## Подробные карты регионов

Региональная карта заменяет участок основной карты более подробным изображением при достаточном увеличении. Она не является игровой зоной и не изменяет правила мира.

Каждый регион хранится отдельным JSON-файлом в `config/decimation/map/regions`. Поддерживается до 32 файлов.

Пример `regions/city_center.json`:

```json
{
  "schemaVersion": 1,
  "id": "city_center",
  "name": "Центр города",
  "dimension": 0,
  "imageUrl": "https://dcmre.work/serverfiles/maps/city-center.png",
  "imageSha256": "",
  "minX": -800,
  "maxX": 600,
  "minZ": -500,
  "maxZ": 900,
  "zoomThreshold": 1.8,
  "priority": 10,
  "enabled": true
}
```

Дополнительные поля:

- `zoomThreshold` — минимальный масштаб, с которого подробное изображение начинает отображаться;
- `priority` — порядок наложения регионов. Регионы с большим значением рисуются позже и перекрывают регионы с меньшим значением;
- `enabled` — позволяет временно отключить регион без удаления файла.

Границы региона должны находиться в координатной системе основной карты этого измерения. Кнопка «Отображение зон» в GUI показывает рамки всех включённых региональных изображений.

После создания или изменения файла выполните:

```text
/deci map reload
```

Проверить загруженные регионы можно командой `/deci map region list`.

## Серверные метки

Серверные метки видят все игроки. Они сохраняются в `config/decimation/map/markers.json` и синхронизируются сервером.

Создавать, редактировать и удалять их удобнее через GUI. Ручное редактирование полезно для массовой настройки.

Пример:

```json
{
  "schemaVersion": 1,
  "revision": 1,
  "markers": [
    {
      "id": "central_trader",
      "dimension": 0,
      "x": 120.0,
      "z": -340.0,
      "category": "Торговцы",
      "title": "Центральный торговец",
      "description": "Оружие, патроны и экипировка",
      "iconUrl": "",
      "iconSha256": "",
      "visible": true,
      "priority": 10,
      "size": 1.5,
      "highlighted": true
    }
  ]
}
```

Ограничения:

- до 2000 постоянных меток;
- `id` должен быть уникальным и соответствовать тем же правилам, что ID карты;
- `category` — до 48 символов;
- `title` — до 96 символов;
- `description` — до 512 символов;
- координаты должны попадать внутрь основной карты соответствующего измерения;
- `visible=false` скрывает метку;
- метки с большим `priority` располагаются выше в списке и имеют приоритет при сортировке.
- `size` задаёт размер метки от `0.5` до `3.0`; старые записи без поля используют `1.0`;
- `highlighted=true` добавляет заметное пульсирующее оранжевое выделение.

`iconUrl` принимает ссылку на сохранённую ItemStack-иконку (`item:<id>`) либо прямую публичную HTTPS-ссылку на PNG/JPG. Для URL-иконок `iconSha256` оставляйте пустым: хэш вводить не требуется. Клиент принимает изображения до 2 МиБ и 1024×1024, блокирует localhost и приватные адреса и сохраняет загруженное изображение в кэше. Для метки без иконки оставьте оба поля пустыми.

## Иконки меток из предметов

Каталог позволяет использовать внешний вид любого предмета как иконку метки. Сохраняется полный ItemStack, включая NBT и модификации оружия; количество нормализуется до одного предмета.

### Добавление иконки

1. Получите права оператора и включите креативный режим.
2. Возьмите нужный предмет в руку.
3. Откройте карту клавишей `M`.
4. Нажмите ПКМ по свободной точке карты и выберите «Создать метку».
5. В редакторе иконок нажмите «Добавить предмет из руки».
6. Укажите понятное название иконки.
7. Выберите созданную иконку и сохраните метку.

Поддерживается до 128 пользовательских иконок. Одна сохранённая иконка может использоваться несколькими метками.

### Изменение и удаление иконки

Нажмите ПКМ по иконке в редакторе метки:

- «Переименовать» — меняет название каталога;
- «Заменить предметом из руки» — обновляет ItemStack, сохраняя ID и привязки всех меток;
- «Удалить» — удаляет иконку после подтверждения.

Если удалить используемую иконку или убрать мод, которому принадлежал предмет, сама метка сохранится и будет показана стандартной нейтральной точкой.

`icons.json` содержит сериализованный NBT в Base64. Не меняйте его вручную. Изменения через GUI сохраняются и рассылаются клиентам автоматически. Если файл всё же менялся вручную, перезапустите сервер: `/deci map reload` не перезагружает каталог ItemStack-иконок.

## Управление через GUI

Для отображения административных действий игрок должен находиться в креативном режиме. Каждое изменение дополнительно проверяется сервером и будет принято только от оператора.

### Создание метки

1. Откройте карту клавишей `M` или командой `/deci map marker gui`.
2. Нажмите ПКМ по свободному месту.
3. Выберите «Создать метку».
4. Заполните название, категорию, описание и координаты.
5. При необходимости нажмите кнопку установки текущих координат игрока.
6. Выберите иконку из каталога предметов, переключитесь на вкладку URL и вставьте прямую HTTPS-ссылку либо оставьте метку без иконки.
7. Настройте размер и при необходимости включите выделение метки.
8. Сохраните.

Системный ID генерируется автоматически и вводить его вручную не нужно.

### Редактирование и удаление метки

1. Нажмите ПКМ непосредственно по серверной метке.
2. Выберите «Изменить» или «Удалить».
3. Удаление требует подтверждения.

### Телепортация

В креативном режиме нажмите ПКМ по нужной точке и выберите «Телепортироваться». Сервер разрешит действие только оператору. Телепортация работает внутри текущего измерения, только в пределах карты, и подбирает безопасную позицию по высоте.

## Команды

Для команд `/deci map` и административных действий в редакторе карты нужны права оператора.

| Команда | Назначение |
|---|---|
| `/deci map reload` | Перезагрузить `map.json`, файлы регионов и `markers.json`. |
| `/deci map region list` | Показать список загруженных регионов и их измерения. |
| `/deci map marker gui` | Открыть карту для администрирования. Для показа админских пунктов включите креатив. |
| `/deci map marker list [страница]` | Вывести по 10 постоянных меток на страницу. |
| `/deci map marker add <название> <категория> <x> <z>` | Быстро создать простую метку в текущем измерении. |
| `/deci map marker remove <id>` | Удалить постоянную метку по ID. |

Команда `marker add` предназначена для коротких значений без пробелов. Для нормального названия, описания, ItemStack-иконки или URL-иконки используйте GUI.

Команды поддерживают табуляцию для подкоманд и ID удаляемых меток.

## Управление картой игроком

### Полноэкранная карта

- `M` — открыть карту;
- ЛКМ и движение мыши — перемещение карты;
- колесо мыши — масштаб;
- `Space` — вернуть стандартный масштаб и центрировать карту на игроке;
- ПКМ по карте — открыть меню действий;
- «Установить метку» — создать личную GPS-метку;
- вкладка «Сервер» — постоянные и динамические серверные метки;
- вкладка «Клиент» — личная GPS-метка и отметка смерти;
- поле поиска — фильтрация по категории, названию и описанию;
- ЛКМ по категории — раскрыть или свернуть список;
- ПКМ по категории — временно скрыть или показать её метки;
- ЛКМ по метке в списке — центрировать карту и установить на неё личную GPS-метку;
- крестик во вкладке «Клиент» — удалить личную метку.

Личная GPS-метка является клиентской: она не сохраняется в серверный конфиг и не видна другим игрокам.

### Предметная карта

- держите предмет карты в руке, чтобы увидеть текущий участок мира;
- положение игрока обозначается поворачивающейся стрелкой;
- ПКМ переключает масштаб `1x → 2x → 4x → 1x`;
- предметная карта использует ту же основную карту измерения, что полноэкранный интерфейс.

## Кэширование изображений

Изображения загружаются клиентом напрямую по HTTPS и сохраняются отдельно для каждого сервера в клиентском кэше `decimation/cache/maps`.

Сервер передаёт клиенту конфигурацию, ссылки и контрольные суммы, но не пересылает сами PNG-файлы. Поэтому хостинг изображений должен быть доступен каждому игроку.

Практические рекомендации:

- используйте PNG или другой формат, который корректно читает Minecraft/Java ImageIO;
- не меняйте содержимое файла по неизменному URL без смены имени или SHA-256;
- не используйте URL страницы просмотра — нужна прямая ссылка на файл;
- проверьте сертификат HTTPS и доступ без авторизации;
- оптимизируйте размер изображения, чтобы вход на сервер не сопровождался долгой загрузкой.

Клиент ограничивает загрузку 16 МиБ, разрешение 8192 × 8192, число перенаправлений и время ожидания. Повреждённое или недоступное изображение не должно останавливать клиент: вместо него карта будет недоступна или покажет запасное отображение.

## Диагностика

### Карта не открывается

1. Проверьте наличие карты в инвентаре или временно установите `requireMapItem=false`.
2. Убедитесь, что для текущего `dimension` есть запись в `map.json`.
3. Выполните `/deci map reload` и прочитайте сообщения в чате/консоли.
4. Проверьте JSON на лишние запятые, Markdown-ссылки и неправильные кавычки.

### Изображение отсутствует

1. Откройте `imageUrl` в браузере без авторизации.
2. Убедитесь, что используется HTTPS и прямая ссылка на файл.
3. Проверьте лимиты 16 МиБ и 8192 × 8192.
4. Если задан `imageSha256`, пересчитайте сумму после каждой замены файла.
5. При замене изображения без SHA измените имя файла/URL, чтобы исключить старый клиентский кэш.

### Карта смещена или растянута

1. Проверьте реальные крайние координаты `minX`, `maxX`, `minZ`, `maxZ`.
2. Убедитесь, что север/верх изображения соответствует `minZ`.
3. Сверьте соотношение сторон изображения с соотношением координатных границ.
4. Создайте временные метки в известных точках и сравните их положение с картинкой.

### Регион не появляется

1. Проверьте `enabled=true`.
2. Убедитесь, что `dimension` совпадает с основной картой.
3. Увеличьте карту до значения не ниже `zoomThreshold`.
4. Проверьте границы региона и прямую HTTPS-ссылку.
5. Выполните `/deci map region list` и `/deci map reload`.

### Админские действия не появляются или отклоняются

- для отображения пунктов GUI включите креативный режим;
- проверьте права оператора;
- координаты метки должны находиться внутри границ основной карты;
- телепортация разрешена только в текущем измерении;
- для ручной правки ItemStack-иконок требуется перезапуск сервера.

### Безопасное обновление конфигов

1. Сохраните копию каталога `config/decimation/map`.
2. Измените нужные JSON-файлы.
3. Проверьте синтаксис JSON.
4. Выполните `/deci map reload`.
5. Если сервер сообщил об ошибке, текущая рабочая конфигурация остаётся активной — исправьте указанный файл и повторите команду.
6. Попросите уже открывших карту игроков закрыть и снова открыть её для получения актуального состояния.
