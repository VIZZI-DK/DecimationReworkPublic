# Зоны: флаги и действия

Откройте редактор командой `/deciserver zones` или `/zone gui`. Для команд и действий в редакторе нужны права оператора. Отметьте два угла инструментом выделения и выберите «Создать из выделения». Координаты включают крайние блоки. В редакторе можно изменить каждый угол, мир, высоту, имя и приоритет.

## Хранение и перенос

Файл: `config/decimation/zones.json`, схема 2. При первом запуске старые зоны автоматически получают ID, имя, мир **0**, флаги соответствующего старого типа и теги для лута. Перед записью создаётся `zones.json.legacy-<время>.bak`; краткий отчёт — `zones-migration.txt`. Последующие сохранения атомарные, с `.backup`. Ошибка чтения не должна заменять существующий файл пустым списком.

Отмена возвращает последнее сохранение за текущий запуск, а не всю историю. Перезагрузка файла очищает отмену. Одновременные изменения администраторов защищены ревизией: устаревшее сохранение отклоняется. Перед сменой выбранной зоны несохранённые правки требуют подтверждения.

## Флаги

Отсутствующее значение наследует правило других пересекающихся зон либо глобальное значение по умолчанию. В GUI нажатие переключает наследование → 1 → 0; пустое числовое поле означает наследование. Выигрывает больший приоритет. При одинаковом приоритете у логических флагов выигрывает 0, у числовых — стабильный порядок ID. Вкладка «Правила» показывает итог и источник **в позиции администратора**.

- `safe` — маркер сейфзоны; он сам не включает весь набор защит. Для этого применить шаблон «Сейфзона».
- `pvp`, `damage`, `infected_damage`, `weapons`, `traps`, `projectiles`, `explosion_damage`, `explosion_blocks`: разрешение соответствующего действия/урона. У снарядов и ловушек сохраняется прежний защитный отступ 10 блоков.
- `radiation`: 0 выключает радиацию, 1 сохраняет прежний урон за импульс, максимум 10. Частота импульсов и защита противогазом остаются прежними. Глобальная настройка радиации по-прежнему действует.
- `thirst`, `hunger`: 0 поддерживает воду/сытость. `infection`, `bleeding`, `broken_legs`: 0 запрещает получение нового состояния, не лечит уже существующее.
- `build`, `break`, `pickup`, `drop`: установка/разрушение блоков, подбор/выбрасывание вещей.
- `containers`: открытие мировых хранилищ; личный инвентарь и меню крафта не блокируются. `loot`: обыск блоков управляемого лута. Права клана/дома и прочие проверки доступа продолжают действовать.
- `houses`: 0 запрещает установку домов внутри и в отступе зоны. `house_margin`: отдельный отступ 0–1000; если не задан, используется конфиг домов. Установка прямо внутри запрещена и при нулевом отступе.
- `zombie_spawn`: разрешение спавна заражённых. Профиль типов зомби во вкладке «Основное» заменяет состав **новых** зомби в точках директора, но не бюджет/таймеры территории и не уже сохранённых зомби. Пустое поле сохраняет профиль территории.
- `rspawn`: разрешает игроку `/rspawn`, но не снимает ограничение боя.
- `scary`: прежний эффект страшной зоны.
- `border`: внутри разрешённой границы; прежний урон снаружи действует только в мирах с включённой границей и при включённом глобальном world border.

У перенесённых сейфзон сохраняется исключение защиты для игрока с активным таймером боя. Все типовые ограничения разбиты на независимые флаги.

Теги (`military`, `police` и прежние типы) сохраняют совместимость категорий лута. Множители групп записываются как `groupID=1.5,anotherGroup=0.5`, допустимо 0–10. Они умножаются на существующие модификаторы таблицы и коррекцию режиссёра; при пересечении зон выбирается один множитель по приоритету, а не произведение всех зон.

## Действия

События: вход, выход, нахождение внутри. Типы: произвольная команда, случайный респавн, сообщение, звук по ресурсному ID. `{player}` заменяется ником. Начальный `/` у команды допустим.

Пример: событие «При входе», тип «Команда», текст `say Welcome, {player}`, «От имени консоли: Да». Команды выполняются в серверном потоке. Без этого переключателя используется обычный отправитель-игрок, без повышения его прав. Сохранение, удаление или изменение зоны с консольным действием требует прав оператора и подтверждения в GUI. Изменения и выполнение команд записываются в серверный журнал `DecimationZones`.

Есть задержка, перерыв между срабатываниями (минимум 1 секунда), отмена при выходе и блокировка во время боя. Задержки используют реальное время. На выходе игрока из сервера его очередь удаляется; изменение конфигурации отменяет отложенные действия старой ревизии. Действия с задержкой не переживают перезапуск. Во время боя заблокированное действие пропускается, а не ожидает конца боя. «Пока внутри» повторяется с заданным перерывом.

Сервер ограничивает исполнение 32 действиями за тик, максимум 4 на игрока, и отменяет устаревшую очередь входа после телепорта. Для обычного входа творческий режим не запускает действие случайного респавна, как раньше. Телепорт из редактора по умолчанию не запускает действия; переключатель позволяет явно проверить вход, в том числе в творческом режиме. Телепорт ищет безопасное место возле центра зоны, не создаёт порталы и не прогружает всю территорию.

Списки разрешённых/запрещённых команд принимают **имена** через запятую, без `/` и аргументов. Разрешение в зоне не заменяет обычные серверные права команды. При равном приоритете запрет выигрывает.

## Проверка в игре владельцем

Автотесты не создавались и не запускались. После установки обновлённых клиента и сервера проверить масштаб GUI, выделение/превью, две пересекающиеся зоны, разные миры, перенос старого файла, консольное действие с задержкой, телепорт с действиями и без них, запрет лута/оружия и радиацию. Предпросмотр показывает границы 120 секунд и не изменяет блоки мира.
