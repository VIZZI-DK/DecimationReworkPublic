# Серверные настройки Decimation Rework

Пути указаны относительно рабочей папки сервера. Основной файл мода — `config/decimation/server.properties`. Обычный `server.properties` в корне относится к Minecraft. После изменения параметров мода выполните `/deciserver reload`. Для отдельных подсистем используйте способы применения из таблицы ниже.

## Основной файл

Значения по умолчанию приведены для нового сервера. Логические параметры принимают `true` или `false`. Для числовых параметров с диапазоном код ограничивает значение указанными границами.

### Режим, игроки и бой

| Ключ | По умолчанию | Эффект |
| --- | --- | --- |
| `dmServer` | `false` | Режим DM, в котором доступны NPC с комплектами снаряжения и применяются правила DM. |
| `enableKillFeed` | `true` | Лента убийств. |
| `enableDeathScreen` | `true` | Экран смерти Decimation. Настройка синхронизируется с подключёнными клиентами при перезагрузке. |
| `requireMapItem` | `true` | Обычным игрокам нужен предмет карты, чтобы открыть полноэкранную карту. |
| `allowRandomSpawns` | `false` | Случайное появление из списка мода при респавне. |
| `enableLegBreaking` | `true` | Получение переломов по правилам мода. |
| `enableBleeding` | `true` | Получение кровотечения. |
| `enableInfection` | `true` | Получение инфекции. |
| `enableIrradiation` | `true` | Радиоактивные зоны могут облучать игроков. Сила зависит от правил зоны. |
| `disableThirst` | `false` | При `true` отключает жажду. |
| `disableExtraArmor` | `false` | При `true` отключает дополнительные элементы брони мода. |
| `disableCorpses` | `false` | При `true` отключает создание тел после смерти. |
| `corpseLifetimeMinutes` | `60` | Срок жизни тела, 1–525600 минут. Отсчёт идёт по тикам мира. |
| `enableInventorySync` | `true` | Синхронизация данных инвентаря и экипировки средствами мода. |
| `enableChatBubbles` | `true` | Индикатор набора сообщения над игроком. |
| `disableClimbing` | `false` | При `true` отключает отдельную механику лазания Decimation. |
| `enableSafezoneGrace` | `true` | Учитывает льготный таймер сейфзоны в проверках урона между игроками. |

### Мир, стройка и лут

| Ключ | По умолчанию | Эффект |
| --- | --- | --- |
| `enableSupplyDrops` | `true` | Автоматические поставки по заданным точкам. |
| `enableBlockBreaking` | `false` | Глобальное разрешение на ломание обычных блоков в выживании. Для фортификаций, креатива и зон действуют отдельные проверки. |
| `blockRegenerationMinutes` | `1` | Задержка восстановления блоков, которые попали в очередь восстановления, 1–525600 минут. |
| `enableBlockPlacing` | `false` | Глобальное разрешение на установку обычных блоков в выживании. Для фортификаций, креатива и зон действуют отдельные проверки. |
| `enableItemPickup` | `false` | Разрешает автоматический подбор предметов с земли в выживании на выделенном сервере. |
| `disableLootSystem` | `false` | При `true` отключает обработку управляемого лута. |
| `lootRespawnTime` | `900` | Секунды для старого таймера лута и исходных настроек новых источников. У источника в `loot/sources.json` свой `respawnMillis`. |
| `maxDemonCount` | `5` | Порог ограничения спавна демонов, 0–1000000. |
| `disableModdedMonsterSpawns` | `false` | При `true` отключает регистрацию обычного спавна монстров мода. Применяйте с перезапуском. Для управляемых зомби есть отдельный редактор популяции. |
| `enableDynamicWeather` | `true` | Управление динамической погодой. |
| `serverFogDensity` | `0.008` | Плотность обычного тумана, 0–1. |
| `serverFogRainDensity` | `0.1` | Плотность тумана при дожде, 0–1. |
| `enableWorldBorder` | `false` | Включает урон за пределами разрешённой области в измерениях, где настроена граница зоны. |

### Подключение, модерация и внешние сервисы

| Ключ | По умолчанию | Эффект |
| --- | --- | --- |
| `allowAdditionalMods` | `false` | При `true` разрешает дополнительные клиентские моды. Проверка совпадения версии Decimation остаётся. |
| `allowedClientMods` | `OptiFine` | Допустимые ID клиентских модов через запятую, без учёта регистра. Установленные на сервере моды тоже учитываются при проверке. |
| `enableAntiDupe` | `false` | Включает проверку инвентарей антидюпом. |
| `enableEnchanting` | `false` | При включённом антидюпе значение `false` позволяет проверке снимать чары с обнаруженных предметов. |
| `enableDebugMode` | `false` | Включает подробные сообщения отладки мода, в том числе диагностику сетевых сообщений. |
| `enableCommunityServerList` | `false` | Разрешает регистрацию сервера в списке сообщества. |
| `enableOfficialStats` | `false` | Разрешает отправку официальной статистики при наличии ключа. |
| `officialServerApiKey` | пусто | Ключ для официальной статистики. Храните его в приватном серверном конфиге. |

`serverType` записывается при создании файла со значением `ZOMBIE_SURVIVAL` и не считывается этим загрузчиком. `enableAutoUpdating`, `disableUpdates`, `motdImage`, `disableClanTags` и `maxEntities` считываются, но в текущем коде нет потребителей этих значений. Встроенная команда проверки обновлений только сообщает об отключении функции. Старые ключи `communityServerId`, `communityServerKey`, `officialServerId`, `officialServerAuthCode`, `disableVPNConnections` и `disableLootDownload` удаляются при загрузке файла.

## Общий файл

`config/decimation/common.properties` читается при запуске мода.

| Ключ | По умолчанию | Эффект |
| --- | --- | --- |
| `allowVanillaMonsters` | `false` | Разрешает ванильных монстров. |
| `constructionHammerBlocks` | `deci:BlockMetalWall` | Список ID блоков через запятую, с которыми может работать строительный молоток. |

## Дома игроков

Файл `config/decimation/houses.properties`. Для ручных изменений используйте перезапуск сервера. Дом здесь означает отдельную систему домов с владельцем, хранилищем, топливом и гаражом. Заборы, вышки и флагштоки используют другую механику.

| Ключ | По умолчанию | Диапазон | Эффект |
| --- | ---: | --- | --- |
| `zoneExclusionRadius` | 200 | 0–100000 | Отступ от зоны, где запрещена установка домов. Флаг `house_margin` может задать свой отступ. |
| `minimumHouseDistance` | 5 | 0–1000 | Минимальная дистанция между домами в блоках. |
| `maxHousesPerPlayer` | 1 | 1–1000 | Максимум домов на игрока. |
| `storageSlots` | 54 | фиксировано | Размер хранилища. Загрузчик записывает 54 обратно в файл. |
| `garageCapacity` | 3 | 0–64 | Максимум машин в гараже. |
| `garageRadius` | 24 | 4–128 | Радиус работы гаража в блоках. |
| `fuelMinutesPerLog` | 180 | 1–525600 | Минуты топлива на одно бревно. |
| `armorDamageIntervalMinutes` | 30 | 1–525600 | Интервал износа хранящейся брони. |
| `weaponConditionLossPerCycle` | 100 | 1–10000 | Потеря состояния оружия за цикл износа. |
| `storedVehiclePartDamageIntervalMinutes` | 360 | 1–525600 | Интервал износа деталей машин в гараже. |
| `maintenanceIntervalSeconds` | 30 | 5–3600 | Период обработки обслуживания. |

## Файлы подсистем и применение изменений

Пути ниже начинаются от `config/decimation/`, если явно не указано хранилище мира.

| Подсистема | Файлы | Где менять и как применять |
| --- | --- | --- |
| Зоны | `zones.json` | Редактор зон сохраняет изменения сразу. После ручной правки используйте «Загрузить файл» или `/zone reload` с правами оператора. [Схема и флаги](zone-flags.md) |
| Старые turf | `turfs.json` | `/turf create`, `/turf remove`, `/turf reload`. |
| Кланы | `clans/config.json`, `clans/data.json`, `clans/journal/`, `clans/archive/` | Цены, уровни улучшений, доход, награды, сроки заявок и приглашений, ограничения журнала меняются в админ-меню. Данные и журнал входят в резервную копию. [Кланы](clan-administration.md) |
| Лут | `loot/groups/*.json`, `loot/tables/*.json`, `loot/sources.json`, `loot/state/` | Редактор сохраняет изменения. После ручной правки выполните `/deciserver loot reload`. Содержимое сгенерированных ящиков хранится отдельно от правил генерации. [Лут](loot-system-admin.md) |
| Режиссёр лута | `loot-director/state.json` | Используйте вкладку режиссёра или `/deciserver loot director`. Здесь хранятся настройки и накопленное состояние. |
| Популяция зомби | `zombies/config.json`, сохранённое состояние в данных мира | Редактор изменяет глобальные лимиты, территории, точки, профили и параметры шума. После ручной правки перезапустите сервер. [Параметры популяции](zombie-population.md) |
| Карта | `map/map.json`, `map/regions/*.json`, `map/markers.json`, `map/icons.json` | `/deci map reload` перечитывает карту, регионы и метки. Каталог иконок редактируется через интерфейс, ручные изменения требуют перезапуска. [Карта](MAP_ADMIN_GUIDE_RU.md) |
| NPC и задания | `quests/catalog.json`, привязки NPC и прогресс в данных мира | Используйте редактор диалогов и заданий. Ручную правку каталога применяйте с перезапуском. [Диалоги](NPC_DIALOGUE_GUIDE.md) |
| Торговцы | `traders.json`, `trades/` | `traders.json` хранит размещение NPC. Каталоги и пользовательские типы хранятся в `trades/`. `/trader reload` перечитывает ассортимент и пересоздаёт торговцев. |
| Точки появления и поставок | `spawnpoints.properties`, `supplydrop.properties` | `/deciserver playerspawn` и `/deciserver supplydrop` меняют списки. |
| Оружие | `weapon-tuning/weapons/`, `weapon-tuning/attachments/`, `weapon-tuning/manifest.json` | Редактор сохраняет профиль и синхронизирует клиентов. Для ручных изменений используйте перезапуск. [Оружие](weapon-tuning-admin.md) |
| Хитбоксы игроков | `player_hitboxes.json` | Редактор сохраняет изменения на сервере. Для ручных изменений используйте перезапуск. |
| Транспорт | `vehicledefs/vehicles/` | `/decivehicles reload` или `/decivehicles sync`. |
| Городская электрика | данные мира `decimation_city_power` | Меню `/deciserver power`. Районы и питание разделены по измерениям. |
| Дома | `houses.properties`, данные мира `decimation_houses`, журналы в `logs/houses/` от корня | Конфиг задаёт лимиты и обслуживание. Меню меняет конкретные дома и глобальную заморозку. |
| Флагштоки и базы игроков | данные мира `decimation_base_flags_<измерение>` и NBT построек | Радиус 60 блоков, обновление раз в сутки, флаг поднят до пяти реальных суток. Срок жизни 45 суток с последнего обновления. Эти значения заданы в коде текущей версии. |

## Дальняя прорисовка LOD

Файл `config/decimation/chunk-render.cfg`, раздел `lod`. Серверный модуль считывает параметры при запуске. Настройки кэша и отрисовки действуют на стороне клиента. Данные сгенерированных регионов находятся в каталоге `decimation_chunk_render` мира. Команды генерации перечислены в [справочнике команд](ADMIN_COMMANDS_RU.md#генерация-дальней-прорисовки).

| Ключ | По умолчанию | Диапазон | Эффект |
| --- | --- | --- | --- |
| `enabled` | `true` | | Включает LOD. |
| `additionalDistanceChunks` | 2 | 0–лимит сервера | Дополнительная дальность в чанках. |
| `maxAdditionalDistanceChunks` | 32 | 1–32 | Верхний предел дополнительной дальности. |
| `generationSamplesPerTick` | 1 | 1–64 | Количество образцов при генерации за тик. |
| `maxGenerationRadiusChunks` | 512 | 1–512 | Верхний предел радиуса генерации. Значение ≤0 заменяется на 512. |
| `generationTickBudgetMicros` | 4000 | 500–20000 | Бюджет времени генерации в микросекундах за тик. |
| `generationWorkerThreads` | 1–4 по числу процессоров | 1–4 | Число потоков генерации. |
| `generationQueueRegions` | удвоенное число потоков | 1–16 | Максимум регионов в очереди генерации. |
| `maxRegionPayloadMiB` | 16 | 1–16 | Максимальный объём данных региона при передаче. |
| `maxRegionTransfersPerPlayer` | 2 | 1–8 | Ограничение передач регионов одному игроку. |
| `maxVboMemoryMiB` | 256 | 1–2048 | Бюджет памяти буферов отрисовки. |
| `maxDecodedRegions` | 128 | 1–1024 | Лимит декодированных регионов в памяти. |
| `diskCacheMiB` | 1024 | 1–16384 | Бюджет дискового кэша клиента. |
| `clientMeshThreads` | 1–2 по числу процессоров | 1–2 | Число клиентских потоков сборки мешей. |
| `clientMeshQueueLayers` | 32 | 4–128 | Максимум слоёв в клиентской очереди сборки. |

Для переноса сервера сохраняйте вместе конфиги и папку мира. Админские действия меняют и настройки, и данные мира. Например, удаление зоны меняет JSON, а удаление дома меняет данные мира. Перед заменой файлов остановите сервер, если подсистема сохраняет изменения в фоне.
